## 🎯 기능 요구사항 확인

### 거래 요약 카드
- [ ] 총 매수 금액이 통화별/기준 통화 합계와 일치
- [ ] 총 매도 금액이 통화별/기준 통화 합계와 일치
- [ ] 순매수(Net) 금액이 매수-매도의 차이와 동일
- [ ] 평균 매수가/매도가와 거래 건수 표시가 정확
- [ ] 손익 색상(`getProfitTextClass`)이 양수/음수/0에 맞게 적용

### 필터 & 탭
- [ ] 종목, 유형(매수/매도/배당), 상태(전체/pending/completed/failed/cancelled) 필터 조합이 정상 동작
- [ ] `자동/수동/전체` 탭 전환 시 리스트 내용이 교체
- [ ] 필터 변경 시 URL 쿼리 또는 상태가 즉시 반영
- [ ] 동일 필터를 재선택 시 중복 API 호출 또는 재렌더링이 발생하지 않음
- [ ] 날짜 범위 선택 시 기간 내 데이터만 노출

### 검색 & CSV 내보내기
- [ ] 검색어 입력 시 실시간으로 리스트가 필터링
- [ ] 검색어/필터/탭 상태가 `localStorage`에 저장되고 새로고침 후 복원
- [ ] CSV 내보내기 클릭 시 현재 필터링된 거래만 포함
- [ ] CSV 헤더와 데이터가 쉼표/따옴표 처리 규칙(CSV RFC) 준수
- [ ] 빈 결과일 때 내보내기 시 경고(Alert) 노출

### 거래 리스트 & 아코디언
- [ ] 종목별 아코디언가 기본 접힘 상태이며 최신 활동이 상단 배치
- [ ] 각 거래 요약 문구가 `"매수 0.01주 @ $X → $Y"` 포맷을 따름
- [ ] `status=pending` 거래는 배경/배지로 강조 표시
- [ ] `purchaseMethod=auto` 거래에 자동 배지가 노출
- [ ] 모바일 뷰에서 카드 레이아웃으로 전환되고 아코디언이 숨김 처리
- [ ] 거래 개수가 많은 경우 가상 스크롤 또는 퍼포먼스 저하 없음

### 거래 상세 팝오버
- [ ] "상세" 버튼 클릭 시 팝오버가 열리고 외부 클릭/ESC로 닫힘
- [ ] 팝오버에서 실행 시간, 수수료, 세금, 메모, 환율, 거래 ID 노출
- [ ] 자동 투자 거래의 예약일/상태가 표시
- [ ] 접근성: 팝오버가 포커스를 가져오고 Tab 탐색이 가능

### 거래 타임라인
- [ ] `주간/월간` 토글 시 타임라인 데이터가 전환
- [ ] 각 구간에 총거래/매수/매도/자동/수동 건수 및 순현금 흐름 표시
- [ ] 상위 심볼 3개의 요약(건수·금액)이 정확
- [ ] 필터(종목/유형/상태/방법/날짜)가 타임라인 API 요청에도 반영
- [ ] 데이터가 없을 때 빈 상태 메시지 및 가이드 노출

## 🧪 기능 테스트

### 정상 플로우
- [ ] 로그인 후 `/transactions` 접속 시 기본 필터(전체/전체/전체/전체)가 적용
- [ ] 필터 변경 → 목록/타임라인/요약 카드가 동기화
- [ ] CSV 내보내기 → 파일 저장 후 Excel/Numbers에서 열기 가능
- [ ] 거래 상세 팝오버 열고 닫은 뒤 다른 거래를 클릭해도 정상 동작

### 데이터 정합성
- [ ] Firestore 거래 문서와 화면에 표시되는 금액/수량/통화가 일치
- [ ] `pending` → `completed` 업데이트 후 새로고침 없이 상태 반영
- [ ] 자동 투자 거래가 `scheduledDate`와 함께 표시되고 `pending` 태그 유지
- [ ] 환율 적용 거래의 총액이 원화/달러 기준에 맞게 환산

### 엣지 케이스
- [ ] 거래 0건일 때 빈 상태 카드와 "거래 추가" CTA 노출
- [ ] 거래 500건 이상일 때 스크롤 성능 확인
- [ ] 동일 종목에 거래 1건만 있을 때 아코디언 단일 카드 처리
- [ ] CSV 내보내기 시 한글/특수문자 데이터가 깨지지 않음
- [ ] 타임라인 API 실패 시 오류 메시지와 재시도 버튼 노출
