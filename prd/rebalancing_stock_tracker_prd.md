# 🎯 리밸런싱 중심 주식 자산 관리 시스템 PRD

> **버전**: v2.0  
> **핵심**: 자동 리밸런싱 추천으로 포트폴리오 최적화  
> **목표**: 개인 투자자의 자산 증식 극대화  
> **업데이트**: 2025년 11월 24일

---

## 🎯 프로젝트 미션

### 핵심 목표
**"리밸런싱으로 수익률을 높이는 스마트 자산 관리 시스템"**

- 포트폴리오 목표 비중 자동 추적
- 분기별 리밸런싱 액션 플랜 자동 생성
- 매수/매도/충전 타이밍을 AI가 추천
- 복잡한 계산 없이 클릭 한 번으로 실행

---

## 💡 핵심 인사이트 (실제 사용자 경험 기반)

### 문제점 발견
```
사용자 실제 포트폴리오 분석 결과:
❌ KODEX 200: 38.7% 비중 (목표 대비 과다)
❌ SCHD: 배당 중심 (자산 증식 목표와 불일치)
✅ MGK, NVDA, BRK.B: 좋은 선택이지만 비중 조정 필요

문제: "어떤 걸 얼마나 사고팔아야 할지 모르겠다"
해결: 리밸런싱 자동 계산 + 실행 가이드 제공
```

### 핵심 차별화
- **기존 서비스**: 단순 포트폴리오 추적, 수익률 계산
- **우리 서비스**: 목표 비중 설정 → 자동 비교 → 구체적 액션 플랜 제공

## 🚀 핵심 기능

### 1️⃣ 스마트 리밸런싱 엔진 (메인 기능)

#### **📊 목표 비중 설정**
```
사용자 입력:
├── 투자 성향 선택
│   ├── 🛡️ 보수적 (안정 70% + 성장 30%)
│   ├── ⚖️ 균형 (안정 50% + 성장 50%)
│   └── 🚀 공격적 (안정 30% + 성장 70%)
│
├── 맞춤 비중 설정 (고급 사용자)
│   ├── NVDA: 19%
│   ├── QQQ: 16%
│   ├── MGK: 15%
│   └── ... (자유롭게 설정)
│
└── AI 추천 비중 (초보자)
    ├── 목표 금액 입력 (예: 1,000만원)
    ├── 투자 기간 입력 (예: 3년)
    └── AI가 최적 포트폴리오 제안
```

#### **🎯 리밸런싱 자동 감지**
```
실시간 모니터링:
├── 현재 비중 vs 목표 비중 계산
├── ±5%p 이상 차이 → 🔔 알림 발송
├── 리밸런싱 필요 종목 자동 표시
└── 예상 효과: +2-3% 연 추가 수익

예시:
┌─────────────────────────────────────┐
│ 🚨 리밸런싱 알림                      │
│                                      │
│ NVDA: 27% (목표 19% +8%p 초과) ⚠️    │
│ → 12만원 매도 추천                    │
│                                      │
│ QQQ: 12% (목표 16% -4%p 부족)        │
│ → 8만원 매수 추천                     │
│                                      │
│ [상세 보기] [지금 실행하기]            │
└─────────────────────────────────────┘
```

#### **⚡ 실전 액션 플랜 생성**
```
리밸런싱 실행 가이드:

Step 1: 매도
✅ NVDA 0.08주 매도 → 약 12만원 확보
   (현재가 $145 기준)

Step 2: 매수  
✅ QQQ $50 매수 → 약 8만원 투자
✅ GOOGL $25 매수 → 약 4만원 투자

Step 3: 결과 예상
📊 목표 비중 달성률: 98%
💰 예상 수수료: 800원
⏱️ 소요 시간: 5분

[복사하기] [증권사 앱 열기] [실행 완료]
```

#### **🔍 통합 주식 등록**
```
주식 검색 & 등록:
├── 🇰🇷 한국 주식
│   ├── 삼성전자, SK하이닉스, 네이버 등
│   ├── KODEX 200, TIGER 나스닥100 등
│   └── 실시간 시세 연동
│

│   ├── AAPL, MSFT, NVDA, TSLA 등
│   ├── QQQ, VOO, MGK, SCHD 등
│   └── 야후 파이낸스 API 연동
│
└── 💰 자동 평가액 계산
    ├── 보유 수량 × 현재가
    ├── 원화/달러 자동 환산
    └── 수익률 실시간 업데이트
```

#### **💵 매수/매도 기록**

**자동 매수 시스템**:
```
리밸런싱 기반 자동 매수:
├── 목표 비중 유지 모드
│   ├── 매일/매주/매월 자동 실행
│   ├── 비중 낮은 종목 자동 매수
│   └── 예시: QQQ가 목표보다 -3%p → 우선 매수
│
├── 정액 적립식
│   ├── MGK 매일 $5 (기존 방식)
│   ├── QQQ 매일 $3
│   └── Toss 증권 연동 가능
│
└── 타이밍 자동 매수
    ├── 급락시 (-10% 이상) 자동 알림
    ├── AI가 저점 예측
    └── "지금 사세요!" 푸시 알림
```

**수동 매수 기록**:
```
직접 매수 후 등록:
├── 종목 선택
├── 매수 날짜 입력
├── 매수 수량 입력
├── 매수 단가 입력 (자동 불러오기 옵션)
└── 수수료 포함/제외 선택

→ 포트폴리오에 자동 반영
→ 비중 재계산
→ 리밸런싱 필요 여부 체크
```

**리밸런싱 추천 매도**:
```
언제 팔아야 할까?

자동 추천:
├── 📈 고평가 종목 (목표 비중 +5%p 초과)
│   ├── "NVDA가 목표보다 8%p 초과했습니다"
│   ├── "12만원어치 매도 추천"
│   └── [매도하기] [나중에]
│
├── 💰 목표 수익률 달성
│   ├── "META가 +30% 수익 달성"
│   ├── "일부 익절 추천 (30%)"
│   └── [익절하기] [더 기다리기]
│
└── 🔄 종목 교체 제안
    ├── "SCHD → QQQ 교체 추천"
    ├── "이유: 성장률 차이 (연 3% vs 18%)"
    └── [교체하기] [유지하기]
```

### 🔄 리밸런싱 엔진 알고리즘

```python
def calculate_rebalancing(portfolio, target_ratios):
    """
    리밸런싱 계산 핵심 로직
    """
    # 1. 현재 비중 계산
    total_value = sum([stock.value for stock in portfolio])
    current_ratios = {
        stock.symbol: (stock.value / total_value) * 100
        for stock in portfolio
    }
    
    # 2. 목표 비중과 차이 계산
    differences = {
        symbol: current_ratios[symbol] - target_ratios[symbol]
        for symbol in target_ratios.keys()
    }
    
    # 3. ±5%p 이상 차이나는 종목 필터링
    needs_rebalancing = {
        symbol: diff 
        for symbol, diff in differences.items() 
        if abs(diff) >= 5.0
    }
    
    if not needs_rebalancing:
        return None  # 리밸런싱 불필요
    
    # 4. 매도/매수 금액 계산
    actions = []
    
    for symbol, diff in needs_rebalancing.items():
        if diff > 0:  # 초과 → 매도
            sell_amount = (diff / 100) * total_value
            actions.append({
                'type': 'SELL',
                'symbol': symbol,
                'amount': sell_amount,
                'reason': f'목표 비중 초과 (+{diff:.1f}%p)'
            })
        else:  # 부족 → 매수
            buy_amount = (abs(diff) / 100) * total_value
            actions.append({
                'type': 'BUY',
                'symbol': symbol,
                'amount': buy_amount,
                'reason': f'목표 비중 부족 ({diff:.1f}%p)'
            })
    
    # 5. 예상 효과 계산
    expected_benefit = calculate_benefit(actions)
    
    return {
        'actions': actions,
        'expected_benefit': expected_benefit,
        'achievement_rate': 98  # 목표 달성률
    }
```

interface RebalancingAction {
  id: string;

    type: 'BUY' | 'SELL';
    symbol: string;
    amount: number;
